Simulation Results

This folder contains figures generated from MATLAB simulations of spacecraft orbital and attitude dynamics.

The results include:

Orbital anomalies versus time

Three-dimensional orbital trajectory in the ECI frame

Numerical versus analytical orbital propagation errors

Specific angular momentum analysis

Orbital trajectory in the ECEF frame

Euler angle and angular velocity evolution

Angular momentum and rotational kinetic energy analysis

These figures illustrate orbital motion, numerical accuracy, reference-frame behaviour, and torque-free spacecraft rotational dynamics.
