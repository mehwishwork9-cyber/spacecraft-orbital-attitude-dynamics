MATLAB Source Code

This folder contains MATLAB scripts and functions developed to investigate spacecraft orbital mechanics and attitude dynamics.

The simulations cover:

Kepler's equation using Newton's method

Classical Orbital Elements (COE) to Cartesian state-vector conversion

Two-body orbit propagation in ECI and ECEF reference frames

Numerical integration using MATLAB ODE45

Direction Cosine Matrix (DCM) transformations

Euler angles and quaternion attitude representations

Torque-free spacecraft rotational dynamics

Angular momentum and rotational kinetic energy analysis

The scripts support the numerical investigations documented in the project report.
